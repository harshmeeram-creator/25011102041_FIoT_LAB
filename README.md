# FUNDAMENTALS OF IoT – LAB ASSESSMENTS

This repository contains the lab assessments completed as part of the **Fundamentals of Internet of Things (FPIoT)** course.

## Repository Structure

### 8051 Microcontroller
Contains assessments from **Week 2 to Week 7**.

### STM32 Microcontroller
Contains assessments from **Week 8 to Week 14**.

## Folder Organization

Each CAT folder represents its respective week.

```text
FUNDAMENTALS_OF_IOT/
│
├── 8051/
│   ├── CAT_02/
│   ├── CAT_03/
│   ├── CAT_04/

│   ├── CAT_06/
│   └── CAT_07/
```

## Contents of Each CAT Folder

Each assessment folder will contain:
- Experiment details
- Hardware setup and platform
- Circuit diagram
- Source code and project files
- Core logic and inference
