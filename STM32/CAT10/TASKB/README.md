# Task B – ESP8266 AT Commands

## Experiment
STM32 and ESP8266 Wi-Fi Communication

## Hardware / Platform
- STM32 Blue Pill (STM32F103C8T6)
- ESP8266 / Wemos Wi-Fi Module
- USB-to-TTL Converter
- STM32CubeMX
- Keil MDK-ARM
- Arduino IDE (for module testing)
- STM32 HAL Library

## Objective
Explore and test the AT command interface of ESP8266.

## Implementation
1. Test basic AT commands.
2. Check module firmware information.
3. Explore Wi-Fi configuration commands.
4. Test network-related commands and examine module responses.

## Core Logic
- Send AT commands through UART.
- Test basic AT commands and firmware information.
- Examine ESP8266 responses.
- Explore Wi-Fi configuration and network-related commands.
