# Task 9A-2 – UART Communication

## Experiment
STM32 UART Communication

## Hardware / Platform
- STM32 Blue Pill (STM32F103C8T6)
- USB-to-TTL Converter
- STM32CubeMX
- Keil MDK-ARM
- PuTTY
- STM32 HAL Library

## Objective
Configure the STM32 UART peripheral for serial communication with a computer.

## Implementation
1. Configure the required UART peripheral using STM32CubeMX.
2. Initialize UART using STM32 HAL functions.
3. Configure the required communication settings.
4. Build and generate the STM32 firmware.

## Core Logic
- Initialize UART communication.
- Configure the required GPIO and UART peripherals.
- Use the generated configuration for serial communication.
