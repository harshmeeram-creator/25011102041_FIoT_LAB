# Task A – On-board LED Bring-Up

## Experiment
STM32 GPIO Experiments

## Hardware / Platform
- NUCLEO-F410RB
- STM32CubeMX
- Keil MDK-ARM
- STM32 HAL Library

## Objective
Configure and control the on-board LED.

## Implementation
1. Configure PA5 as GPIO output.
2. Initialize the GPIO peripheral.
3. Implement LED blinking using GPIO operations.

## Observation
The on-board LED blinked as expected.

## Core Logic
- Configure PA5 as GPIO output.
- Initialize the GPIO peripheral.
- Toggle the LED continuously.
